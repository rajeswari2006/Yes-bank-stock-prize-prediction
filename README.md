# Yes Bank Stock Price Prediction

Hi! I'm Rajeswari and this is my beginner-level machine learning project where I predict the stock trend of Yes Bank using logistic regression and XGBoost models.

## Project Overview

In this notebook, I worked with real stock market data of Yes Bank. I focused on predicting whether the stock price would go up or down the next day using some smartly engineered features like:

- `Open-Close` difference
- `High-Low` difference

This project helped me explore important concepts like:
- Data cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training and prediction
- Visualization

---

## Tools & Libraries Used

- Python
- Pandas, Numpy
- Matplotlib, Seaborn
- Scikit-learn
- XGBoost

---

## Models Used

1. **Logistic Regression**
2. **XGBoost Classifier**

I visualized the model predictions and tried to compare their performance. XGBoost performed better due to its boosting nature.
